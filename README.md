# Vietnamese OCR with LLM

A Vietnamese document-recognition application that combines OCR with a Large Language Model to extract text, interpret content, and support summarization.

## Overview

This project was developed as a group project for the Exploring Computer Science course at Vietnamese-German University.

The system evaluates multiple OCR approaches and combines the selected OCR pipeline with the ChatGPT API.

## Features

- Vietnamese text recognition
- Image and camera input
- Graphical user interface
- LLM-based interpretation and summarization
- OCR performance testing
- Platform-specific installation requirements

## Technologies

- Python
- Vintern-1B-v2
- ChatGPT API
- Pygame
- Computer vision
- OCR
